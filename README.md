# zenbpm-adapter

The [VanillaBP](https://www.vanillabp.io) adapter for the [ZenBPM](https://github.com/pbinitiative/zenbpm)
engine, owned by the ZenBPM maintainers.

Nothing is implemented yet. The analysis, the architecture and the implementation plan live in
[`docs/`](docs/README.md); start with its index. The first stories of the plan turn this file into the
contributor README the other VanillaBP adapters have.
